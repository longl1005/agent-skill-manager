## Highlights

- **MiniMax Code support** — connect MiniMax Code as a first-class Agent and manage all Skills in its configured Skills directory.
- **Settings that fit your workflow** — choose how the app stays available, including dock and menu-bar behavior.
- **Proxy configuration** — configure a network proxy from Settings when your environment requires one.
- **Easier macOS installation** — releases now include separate DMG installers for Apple Silicon and Intel Macs.
- **More reliable Skill installation** — fixes improve Windows installation and repositories that contain multiple Skills.

## 中文摘要

- **支持 MiniMax Code**：将 MiniMax Code 作为 Agent 接入，扫描和管理其 Skills 目录中的全部技能。
- **更灵活的通用设置**：可按习惯调整应用在 Dock 与菜单栏中的驻留方式。
- **支持代理配置**：可在「设置」中配置网络代理，适配受限网络环境。
- **更易安装的 macOS 版本**：现提供 Apple 芯片与 Intel 芯片分别对应的 DMG 安装包。
- **技能安装更稳定**：修复 Windows 安装以及多 Skill 仓库安装时的问题。

## Installation note / 安装提示

This release is not distributed with an Apple or Microsoft trusted developer certificate. macOS builds are ad-hoc signed but not notarized, so Gatekeeper may require you to Control-click the app and choose **Open** on first launch. Windows SmartScreen may also show a warning; review the source and continue only if you trust it.

本版本暂未使用 Apple 或 Microsoft 的受信任开发者证书。macOS 安装包采用临时签名但未经过公证，首次打开时如被 Gatekeeper 拦截，请按住 Control 点击应用并选择「打开」。Windows SmartScreen 也可能显示提示；请确认来源可信后再继续。
