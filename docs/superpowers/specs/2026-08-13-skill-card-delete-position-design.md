# 技能卡片删除图标定位设计

## 目标

将 Agent 详情页技能卡片的删除图标固定为常显的右上角操作，避免它占用标题行宽度或挤压长技能名称。

## 交互

- 删除图标始终显示在每张技能卡片右上角。
- 图标使用绝对定位，不参与标题行的 flex 布局。
- 点击图标继续阻止卡片链接跳转，并打开现有删除确认流程。
- 悬停、键盘聚焦、禁用态和删除错误提示保持现有语义与行为。

## 布局与样式

- 技能卡片作为定位容器，右上角保留固定内边距。
- 标题和描述区域增加右侧安全留白，避免长标题、描述与删除图标重叠。
- 保持现有卡片高度、技能图标位置、文件数量和主库状态标签的位置。
- 删除按钮继续常显，并使用现有主题变量适配亮色、暗色及自定义配色方案。

## 实现范围

- 调整 Agent 详情页技能卡片中删除按钮的结构类名或定位样式。
- 更新技能卡片头部与正文的间距规则。
- 添加回归测试，验证删除按钮仍可访问且点击不会触发卡片导航。

## 非目标

- 不修改删除确认弹窗、删除 API、上传主库或技能卡片排序。
- 不把删除按钮改为悬停显示。
- 不调整其他页面的删除入口。

## 验收标准

- 每张 Agent 技能卡片的删除图标常显于右上角。
- 长标题和描述不被删除图标遮挡。
- 点击删除图标仍只打开删除确认，不导航到技能详情。
- Agent 详情页测试、全量前端测试、生产构建和差异检查通过。
