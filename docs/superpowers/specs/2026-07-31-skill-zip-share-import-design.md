# Skill ZIP 分享与本地导入

## 目标

让主技能仓库中的单个 skill 能导出为可分享的 `.zip` 文件，并让安装页的“本地导入”支持文件夹和该 `.zip` 文件，导入后沿用既有的主库安装与 Agent 分发流程。

## 分享

- 主技能卡片在“打开目录”和“删除”之间增加分享按钮。
- 点击后显示系统保存文件对话框，默认文件名为 `<skill-name>.zip`。
- ZIP 根目录为 `<skill-name>/`，保留技能目录的全部常规文件和子目录，包含 `SKILL.md`。
- 用户取消保存不报错，也不修改主库。

## 本地导入

- “本地目录导入”改名为“本地导入”。
- 文件选择器允许选择一个目录或一个 `.zip` 文件；拖放区同样接受两者。
- 文件夹导入保持现有行为。
- ZIP 导入先解压到应用专用临时目录，从压缩包根目录或其单一顶层目录查找 `SKILL.md`，再交由既有安装流程复制到主库并分发。

## 安全与错误处理

- 只接受扩展名为 `.zip` 的压缩文件。
- 解压前逐条拒绝绝对路径、`..` 路径段和无法归属到临时目录的条目，防止 Zip Slip。
- 拒绝不含 `SKILL.md` 的目录或 ZIP，并向用户显示明确错误。
- 临时解压目录无论成功、失败或取消安装都清理。
- ZIP 读取或写入失败不得影响已有主库技能。

## 跨平台

- 使用 Rust ZIP 库创建和解压 ZIP，不调用 macOS、Windows 或 Linux 的系统压缩命令。
- 保存位置通过 Tauri Dialog 插件取得，因此 macOS 和 Windows 安装包具有一致交互。

## 验证

- Rust 测试覆盖导出 ZIP 结构、合法 ZIP 导入、缺少 `SKILL.md`、Zip Slip 和清理临时目录。
- 前端测试覆盖分享调用保存路径、文件夹选择、ZIP 选择及 ZIP 导入标签。
