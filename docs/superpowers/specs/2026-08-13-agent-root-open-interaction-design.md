# Agent 详情页目录打开交互设计

## 目标

让用户可以直接从 Agent 详情页头部打开对应的技能目录，并让单目录 Agent 与多目录 Agent 使用一致、易发现的交互方式。

## 交互设计

- 目录路径本身作为可点击的目录标签，不额外增加独立的“打开目录”按钮。
- 单目录 Agent 将当前纯文本路径改为带边框的目录标签；点击标签打开该目录。
- 多目录 Agent 保留现有目录标签；点击不同标签分别打开对应目录。
- 标签增加文件夹图标，强化“打开目录”的操作含义。
- 鼠标悬停时提高边框和文字对比度；键盘聚焦时显示清晰的焦点环。
- 路径过长时保持单行省略，通过 `title` 展示完整目录信息。

## 状态与行为

- 使用 Agent 扫描结果中的 `root.display_path` 作为打开目录参数。
- 单目录 Agent 使用唯一目录；多目录 Agent 使用当前被点击标签对应的目录。
- 没有检测到技能目录时继续显示原有空状态文本，不渲染可点击标签。
- 目录打开失败继续交由现有 Tauri 命令错误处理，不改变扫描或刷新状态。

## 可访问性与文案

- 每个目录标签使用原生 `button`，支持鼠标、键盘与辅助技术操作。
- 为按钮提供包含完整路径的可访问名称和悬停提示。
- 中文与英文界面复用现有“打开目录”本地化文案；目录类型标签继续使用现有翻译。

## 实现范围

- 调整 `AgentDetail` 头部的单目录路径渲染，使其复用多目录标签的打开行为。
- 统一单目录与多目录标签的图标、截断、悬停和焦点样式。
- 补充路由测试，覆盖单目录和多目录 Agent 打开正确目录的行为。
- 复用现有 `openSkillDirectory` IPC，不新增 Rust 命令或数据结构。

## 非目标

- 不增加目录选择弹窗或下拉菜单。
- 不改变 Agent 技能扫描、排序、刷新和删除逻辑。
- 不改变设置页中的 Agent 目录配置方式。
- 不调整技能卡片或侧边栏布局。

## 验收标准

- 单目录 Agent 点击目录标签后，以该 Agent 的技能目录调用打开目录命令。
- 多目录 Agent 点击任意目录标签后，以对应标签的路径调用打开目录命令。
- 过长路径不会撑破详情页头部布局，并可查看完整路径。
- 标签在亮色、暗色及其他现有主题下均保持清晰的悬停和键盘焦点状态。
- Agent 详情页测试、全量前端测试、生产构建及差异检查通过。
