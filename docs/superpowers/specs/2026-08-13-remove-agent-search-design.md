# Agent 管理页精简头部信息设计

## 目标

移除设置页“Agent 管理”中的名称/路径搜索条件和“已启用 · 已检测”汇总，让页面直接进入完整的已检测 Agent 列表，并继续通过“更多 Agent”折叠区管理未检测 Agent。

## 界面设计

- 删除工具栏左侧搜索框及搜索图标。
- 删除右侧“已启用 · 已检测”汇总及承载它的独立工具栏，不保留空白占位。
- “已检测到的 Agent”数量始终显示实际检测总数。
- 已检测 Agent 始终完整展示，不再出现“没有匹配的已检测 Agent”空状态。
- “更多 Agent”只由用户点击展开或收起，不再因搜索内容自动展开。

## 状态与数据流

- 删除 `agentSearch` 本地状态。
- 删除搜索词归一化、名称/ID/路径匹配及两组过滤结果。
- 删除只服务于汇总文案的已启用 Agent 数量计算。
- 已检测列表直接使用 `detectedAgents`，更多列表直接使用 `moreAgents`。
- Agent 启用、关闭、拖动排序、路径编辑和列表标题计数逻辑保持不变。

## 样式

- 删除只服务于搜索框的 `.settings-search-field` 样式和焦点选择器。
- 删除 `.settings-agent-toolbar`、`.settings-agent-toolbar__count` 及其响应式规则。
- 不修改主题 Token、列表结构、卡片间距或响应式断点。

## 测试与验收

- 将原搜索过滤测试替换为“页面不渲染搜索框且完整展示已检测 Agent”的回归测试。
- 断言页面不再渲染“已启用 · 已检测”汇总，同时仍显示“已检测到的 Agent”标题及其数量。
- 验证“更多 Agent”默认仍为收起状态，点击后正常展开。
- 运行设置页测试、全量前端测试、生产构建和 `git diff --check`。

## 非目标

- 不新增其他筛选条件。
- 不改变 Agent 排序和启用状态。
- 不删除列表标题旁的已检测数量。
- 不修改 Rust、数据库或扫描逻辑。
