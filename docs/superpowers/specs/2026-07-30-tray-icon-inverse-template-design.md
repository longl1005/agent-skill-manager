# 托盘图标反白模板设计

## 目标

提升 macOS 菜单栏中 Agent Skill Manager 托盘图标的可见性与应用归属感，替换当前偏小的三节点线条图标。

## 视觉规格

- 画布：18 × 18 px，RGBA PNG。
- 外轮廓：沿用应用图标的圆角方形比例，约占 15 × 15 px，并保持四周安全边距。
- 主体：实心白色圆角方形。
- 中央：三节点连接图形为透明镂空，显示菜单栏本身的颜色；形态必须与应用 icon 一致：上方一个圆节点、下方左右各一个圆节点，三条连接臂在中心汇合。
- 不使用蓝色、阴影、渐变、描边、文字或额外装饰。

## 平台行为

- macOS：继续作为模板图标加载；图像的 alpha 形状决定系统着色区域，中央镂空保持透明。因此深色菜单栏中会呈现浅色圆角主体与深色镂空图形，浅色菜单栏中自动反向适配。
- Windows：不受此资源影响，继续使用彩色应用图标。

## 托盘唤起行为

- 托盘菜单首项固定为“显示主窗口”（英文为 “Show Main Window”），不再提供“显示 / 隐藏主窗口”的切换操作。
- 选择该菜单项或左键点击托盘图标时，均只执行显示并聚焦主窗口；窗口已经可见时保持可见，不执行隐藏。
- 用户关闭主窗口时，现有的“隐藏到托盘、后台继续运行”行为保持不变；托盘只作为单向找回主窗口的入口。

## 验收标准

1. 菜单栏图标在深色背景上明显大于当前的细小符号，且视觉上与应用图标一致。
2. 四个角完全透明，不出现方形底板。
3. 中央三节点区域为透明镂空，而不是白色或黑色填充。
4. `tray-template.png` 保持 18 × 18、具有 alpha 通道；macOS `icon_as_template(true)` 保持启用。
5. 重建 macOS `.app` 后，手工验证浅色与深色菜单栏中的可读性。

## 范围

替换 `src-tauri/icons/tray-template.png`，并将托盘菜单与左键点击统一为单向显示主窗口；不改变关闭窗口后的隐藏行为或 Windows 图标策略。
