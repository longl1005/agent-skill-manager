# 配色方案与主题风格设计

## 背景

当前应用只维护 `system`、`light`、`dark` 三种明暗模式，并由单一 `data-theme` 属性控制全部语义颜色。设置页将它们展示为“外观主题”，无法在明暗模式之外选择独立的视觉风格。

本次调整把“明暗模式”和“主题风格”拆成两个正交维度：配色方案决定浅色或深色，主题决定强调色和表面色。用户可以任意组合，系统模式变化也不会覆盖主题选择。

## 目标

- 将现有“外观主题”改名为“配色方案”，使用下拉框选择跟随系统、浅色或深色。
- 新增“主题”下拉框，首版提供 Graphite、Aura、Jade。
- 三套主题都支持跟随系统、浅色、深色三种配色方案。
- 选择后立即预览并持久化，不增加确认或应用按钮。
- 默认保持 Graphite，确保升级后的现有用户不发生意外视觉变化。
- 保持现有布局、字体、间距、圆角、阴影层级和组件结构不变。

## 非目标

- 不支持用户自定义颜色或导入主题文件。
- 不提供在线主题市场、主题下载或跨设备同步。
- 不修改 Rust、数据库或诊断报告格式。
- 不让主题改变布局密度、字体、动效或组件几何形态。

## 设置页交互

“通用设置”按以下顺序展示三行设置：

1. **配色方案**：跟随系统、浅色、深色。
2. **主题**：Graphite、Aura、Jade。
3. **语言**：简体中文、English。

三个控件使用一致的右侧原生下拉样式，包含可见标签、键盘焦点和系统原生菜单行为。选择值后立即更新整页视觉并写入本地存储。

当配色方案为“跟随系统”时，操作系统的明暗变化只更新有效配色，不改变当前主题。用户切换主题时，当前有效明暗模式保持不变。

## 状态模型与持久化

现有主题 Store 扩展为两个独立状态：

- `themeMode`: `system | light | dark`
- `themeStyle`: `graphite | aura | jade`

本地存储键：

- `asm_theme_mode`：沿用现有键，保留用户的明暗模式选择。
- `asm_theme_style`：新增键；不存在或值无效时回退到 `graphite`。

应用启动和每次设置变化时统一应用两个根节点属性：

- `data-theme="light|dark"`：表示计算后的有效明暗模式。
- `data-theme-style="graphite|aura|jade"`：表示主题风格。

系统媒体查询监听器仅在 `themeMode` 为 `system` 时更新 `data-theme`。任何非法缓存值都在进入 DOM 前归一化到安全默认值。

## CSS Token 结构

采用双维度 Token 矩阵，为 Graphite、Aura、Jade 分别维护浅色和深色变量，共六套明确配色。

Graphite 是完整基础主题，保留当前配色。Aura 和 Jade 使用组合选择器覆盖完整语义变量；若新增组件只消费语义 Token，就会自动适配所有组合。

每套组合至少定义以下 Token：

- 页面与容器：`canvas`、`surface`、`surface-hover`、`sidebar`、`line`
- 文字：`text`、`muted`
- 操作：`accent`、`control-accent`、`control-accent-hover`、`control-accent-pressed`、`control-switch-off`
- 状态：`success`、`warning`、`danger`
- 兼容别名：`bg`、`fg`、`border` 和现有 Agent 页面别名

主题方向：

- **Graphite**：现有中性石墨表面和蓝色强调色，作为所有用户的默认主题。
- **Aura**：紫蓝强调色和冷调紫灰表面，强调辨识度但避免高饱和霓虹效果。
- **Jade**：青绿色强调色和轻微墨绿表面，降低长时间使用时的视觉刺激。

所有主题保持红色危险语义、绿色成功语义和黄色警告语义，允许色调适配但不改变含义。普通文字与背景对比度至少为 4.5:1；边框、焦点环和图标在两种明暗模式下都必须可辨认。

## 应用流程

1. Store 初始化时读取并校验两个本地设置。
2. 根据 `themeMode` 和系统媒体查询计算有效的 `light` 或 `dark`。
3. 在根节点同步设置 `data-theme` 和 `data-theme-style`。
4. 设置页下拉框只调用 Store action，不直接操作 DOM。
5. Store action 同步更新状态、本地存储和根节点属性。

整个流程同步执行，不依赖网络、数据库或后端命令，因此不需要加载态和失败弹窗。

## 兼容与回退

- 已有 `asm_theme_mode` 保持有效，不进行迁移或重写。
- 所有用户在没有 `asm_theme_style` 时使用 Graphite。
- Graphite 提供完整基础 Token；Aura 或 Jade 的缺失变量可继承 Graphite，避免界面失去样式。
- 未识别的主题值和配色方案值不会写入 DOM，而是回退到 Graphite 和 System。

## 测试与验收

自动化测试覆盖：

- Store 默认值为 Graphite，非法缓存值正确回退。
- 修改配色方案会更新有效 `data-theme`，但不改变主题。
- 修改主题会更新 `data-theme-style`，但不改变有效明暗模式。
- 系统明暗事件只在 System 模式下生效。
- 设置页两个下拉框包含正确选项，切换后立即更新并持久化。
- 中英文标签与选项正确。

视觉验收覆盖：

- Graphite、Aura、Jade 在浅色与深色下的六种组合。
- 系统模式随操作系统切换时主题保持不变。
- 标准窗口和窄窗口均无横向溢出。
- 下拉框支持鼠标、键盘和读屏器，焦点状态清晰。
- 普通文字满足 4.5:1 对比度，状态含义不只依赖颜色。
