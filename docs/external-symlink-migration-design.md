# 外部软链接迁移到主库设计

## 目标

允许用户将 Agent Skill 列表中的外部目录软链接导入主库，并将当前 Agent 的链接安全地重定向到主库副本，方便后续统一管理和迁移。

## 交互

外部软链接卡片显示“上传至主库”操作。点击后显示确认框，列出 Skill 名称、外部目标路径和结果：外部目标不会删除；当前 Agent 的软链接会改为指向主库。

若主库已有同名 Skill，用户必须选择：取消、覆盖主库、或保留主库并仅将当前链接改为指向主库。

## 迁移流程

1. 后端读取当前 Agent 位置的软链接并解析目标。
2. 仅接受目录目标且要求其包含有效 `SKILL.md`。
3. 无冲突时，复制目标目录到主库；覆盖时，先复制到临时目录，完整成功后再原子替换主库目录。
4. 当主库副本已经准备好后，删除当前 Agent 的软链接本身，并创建指向主库的新软链接。
5. 返回刷新后的扫描结果。

复制、校验或冲突处理失败时，不删除或改写原 Agent 软链接。任何情况下都不删除外部目标目录。

## 文件系统边界

仅跟随当前待迁移的顶层软链接以读取其 Skill 目录；复制过程不跟随内容内部的软链接，沿用现有安全扫描策略，避免复制任意外部文件。

## 测试

- 有效外部链接迁移后指向主库，外部目标仍存在；
- 失效链接、文件目标或缺少 `SKILL.md` 的目标被拒绝；
- 三种同名冲突选择行为正确；
- 复制失败时原链接和原主库内容保持不变；
- UI 显示导入与确认流程，并在成功后刷新。
